# Video Downloader v5 Web MVP

## Развёртывание
1. Создай GitHub-репозиторий и загрузи содержимое проекта.
2. Render → New → Web Service → подключи репозиторий.
3. Используй Docker runtime и Free plan для теста.
4. После Deploy открой адрес `*.onrender.com`.
5. На телефоне или ПК: URL → Найти → качество → дождаться 100% → Скачать.

Можно также использовать `render.yaml` через Render Blueprint.

## Особенности MVP
- Один сервер одновременно обрабатывает одно тяжёлое скачивание.
- Готовые файлы удаляются примерно через час.
- Защитный лимит готового файла: 750 МБ (`MAX_FILE_MB`).
- Cookies в публичный GitHub не загружать.
- Некоторые видеосервисы могут ограничивать IP дата-центров.
- DRM не обходится.
